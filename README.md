# Tessera — анализатор места на диске для macOS

Нативное приложение (Swift, AppKit + SwiftUI), показывающее содержимое диска в виде
живой treemap-карты: чем больше прямоугольник, тем больше файл или папка. Карта растёт
прямо во время сканирования, по ней можно «проваливаться» внутрь, фильтровать, помечать
файлы тегами, удалять лишнее в Корзину и сохранять снимки сканирования.

## Сборка

Нужен Mac с macOS 13+ и Xcode 15+ (или Command Line Tools: `xcode-select --install`).

```bash
swift test                      # тесты ядра (фильтры, раскладка, экспорт, снапшоты, реальный скан)
bash scripts/build-app.sh       # → build/Tessera.app
open build/Tessera.app
DMG=1 UNIVERSAL=1 bash scripts/build-app.sh   # универсальный .app + build/Tessera.dmg
```

Поделиться с тестерами: `bash scripts/make-dmg.sh` → `build/Tessera-<версия>.dmg`
(универсальная сборка Apple silicon + Intel; внутри — инструкция по первому запуску).

Приложение подписано ad hoc. При первом запуске macOS может спросить подтверждение:
правый клик по Tessera.app → «Открыть».

Чтобы видеть весь диск, выдайте **Полный доступ к диску**: Системные настройки →
Конфиденциальность и безопасность → Полный доступ к диску → добавить Tessera.
Без этого защищённые папки попадают в лог и показываются как «неизвестное» место.

Без Mac: запушьте репозиторий на GitHub — `.github/workflows/build.yml` соберёт и
протестирует проект на macOS-раннере и выложит `Tessera.dmg` в артефакты.

## Что умеет

- Стартовый диалог: диски с заполненностью, несколько путей через `;`, «Выбрать…»,
  перетаскивание папок и снапшотов.
- Многопоточный скан, карта обновляется на лету; размер «на диске» или «данных»;
  жёсткие ссылки считаются один раз; на `/` правильно обходит APFS (Data-том, firmlinks).
- Вложенная squarified-карта с заголовками папок, уровень детализации (⌘− / ⌘+),
  клик — выбор и «раскопка», двойной клик — анимированный зум, ⌫ / ⇧⌫ / ⌘↑ / ⌘⇧↑,
  жест щипка, свайп.
- Свободное и «невидимое» место на томе, полоса «какая доля диска на экране».
- Подсветка под курсором с ореолом родителей, тень у выделения, мигание изменённых файлов.
- Живое отслеживание изменений через FSEvents (даже после остановки скана), подскан папки.
- Язык фильтров: `*.jpg`, `|*.dmg`, `\cache`, `>100mb`, `size>10 mb`, `>1year`,
  `a>6months`, `:red`, `:tag:red+green-b`, `:attr:hidden`, `:class:Video`, комбинации через `;`,
  нечёткие ключевые слова (`dsksz`). Справка: Help › Filtering.
- Четыре цветных тега (1–4 или ⌃1–⌃4), теги папок наследуются в фильтрах, ⌃0 — очистить.
- Контекстное меню: Открыть, Показать в Finder, Quick Look (пробел), Копировать путь,
  Пересканировать, Тег, В Корзину (с предупреждением, если фильтр скрывает часть папки).
- Экспорт: свой формат снимка `.tessera` (открывается обратно, «не живой» режим),
  CSV/outline/по папкам, редактор своих шаблонов на мини-языке
  (`<%pathfile%>`, `{leftpad{…}{…}{…}}`, `{if{a}>{b}?{…}:{…}}`, `{script}` …) с превью.
- Импорт вывода `du -ak` с другой машины.
- Настройки: размер подписей, мин. размер элемента, пропорции, детализация, анимация,
  частота перерисовки с авто-замедлением, контраст глубины и границ, ореол, цвета,
  редактор «видов файлов».
- Интерфейс на английском и русском (Настройки › Основные › Язык), включая справку.
- Проверка полного доступа к диску в Настройках › Основные.
- Лог с подсказками и кнопкой «Полный доступ к диску», справка, командная строка:

```bash
build/Tessera.app/Contents/MacOS/Tessera scan ~/Downloads filter "*.dmg;>100mb" \
    export "Files as CSV" ~/big-dmgs.csv autoclose
```

## Устройство

```
Sources/TesseraCore/   ядро без UI: FileNode, ScanEngine (opendir/fstatat в потоках),
                       ScanSession (слияние в дерево на main, FSEvents, фильтр),
                       TreemapLayout, Filter, ExportScript/Export, Snapshot, LaunchCommands
Sources/Tessera/       приложение: AppDelegate (меню, CLI), ScanWindowController,
                       TreemapView (рисование, мышь, клавиатура), окна на SwiftUI
Tests/TesseraCoreTests XCTest
```

## Если сборка падает

Код писался без доступа к компилятору Swift (сервер на Linux), поэтому на первой сборке
возможны мелкие ошибки компиляции — чаще всего про изоляцию `@MainActor` или сигнатуры
AppKit в конкретной версии SDK. Пришлите вывод `swift build` — исправлю.
